# DPR Generator — First Fix × MBL

Daily Progress Report generator web app.

## Deploy to Vercel

1. Push this folder to a GitHub repo
2. Go to vercel.com → New Project → Import your repo
3. Click Deploy — done!

## Usage

1. Open the app link
2. Fill in date, report number, supervision, labors
3. Upload Excel files from foremen
4. Upload site photos
5. Click Generate → download PDF & Word
